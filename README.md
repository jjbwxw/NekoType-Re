# NekoType-Re

这是 [NekoType](https://github.com/Yukstarlight/NekoType)（原作者 Yukstarlight）的二改版，不是官方的。原项目是 GPL-3.0，这里也继续按 GPL-3.0 开源，感谢原作者。

原版是 Android 上的一个消息文本自定义工具：悬浮球常驻屏幕边缘，点一下就把输入框里的字按规则（前缀 / 后缀 / 替换这些）改写后自动发送。原版有什么功能、怎么用、常见问题，都在官方 README 里，这里不重复贴了，只说这个二改版改了什么。

## 加了个 AI 改写

光靠规则改不动语气？可以把整句话交给 AI 来改：

* 设置页「AI 改写」卡片里填 OpenAI 兼容的接口地址、API 密钥和模型名，DeepSeek、智谱 GLM、Kimi、OpenAI、硅基流动这些都行。地址按 base_url 的习惯填就行，缺 `/chat/completions` 会自动补上。联网部分是手写的 HttpURLConnection，没引第三方库
* 只有点悬浮球（含摇一摇）改写时才会调 AI。点了球会提示「AI 改写中…」，AI 的结果直接替换规则改出来的结果发出去；AI 超时、报错或者改完跟原文一样，就还用本地规则的结果
* 超时、断网这种网络问题会自动再试一次（密钥填错这种就不会白等了）；再不行就走本地规则
* 内置 9 套人设提示词：智能润色、萝莉语、古风文言、译制片腔、阴阳怪气、火星文、病娇、雌小鬼、猫娘（火星文、猫娘跟原版的内置规则包风格对齐）。提示词有三种用法：跟着当前预设走（比如切到病娇预设，AI 就用病娇的口吻）、固定用某一套、或者整段 system 提示词自己写
* 服务商档案：接口、密钥、模型可以存成好几个档案（比如一套 DeepSeek 一套 GLM），切换时不用重新填
* 长按悬浮球的快捷菜单里加了「AI 改写」页，开关 AI、换人设不用进设置页
* 改写历史：最近 20 条原文和改写结果（失败的记失败原因）存在本机，设置页可以看、可以一键清空
* 防串扰：等 AI 的时候又点了一次球，旧的请求结果会作废，不会覆盖新的一轮；原文和结果都有 4000 字上限；模型输出会自动剥掉引号和「改写：」这种前缀
* 说清楚：开了这个功能，你点悬浮球那条消息的文字会发给你自己填的服务商，用哪家的服务自己掂量。密钥、档案、历史都只存在手机上，导出配置文件里没有这些。应用因此多了个 INTERNET 权限，不开 AI 就不会联网

不开 AI 改写就跟原版一样完全不联网，规则什么的都在本地，原版的隐私说明也照旧适用。

## 其他改动

* 包名从 com.nekotype.app 改成了 com.nekotype.app.re，能跟官方版同时装在一台手机上，互不影响；桌面显示名还是 NekoType
* 版本号在官方版本号后面加个 -re，当前是 v2.9.10-re，基于官方 v2.9.9 改的
* 终端 HOME 改成运行时取真实数据目录；防篡改改成签名不匹配只记日志不拦截（GPL-3.0 不该拦别人自己编译的包），Hook 框架检测照旧拦

## 安装

* 到 [Release](https://github.com/jjbwxw/NekoType-Re/releases) 页下 APK 装上就能用，是 debug 签名的
* 包名不同，不能在官方版上直接覆盖升级。想把规则搬过来：先在官方版「导出配置」，装好这个再「导入配置」
* 原版的下载、完整文档、反馈渠道都在官方仓库：https://github.com/Yukstarlight/NekoType
